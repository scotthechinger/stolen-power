# People-Centered Power — prototype

A working prototype for Advancement Project's People-Centered Power campaign, built by [Zealous](https://zealo.us).

**This is not a design.** It is a structural and language prototype — the type, color, layout and imagery are scaffolding so the pages could exist and be clicked through. It exists to show the user experience and to let the language be edited from an informed position.

## Pages

| File | What it is |
|---|---|
| `index.html` / `pcp-home.html` | Homepage |
| `how-it-happens.html` | The scrollytell — pick a problem, walk a path |
| `history.html` | The timeline — nine eras |
| `tracker.html` | Legislative tracker |
| `voices.html` | Archive of first-hand accounts |
| `find-your-campaign.html` | US map of past and present fights |
| `place-houston.html`, `place-jackson.html`, `place-virginia.html`, `place-stlouis.html` | Anchor place pages |
| `about.html` | About this project |

`index.html` is a copy of `pcp-home.html` so the site's root URL resolves. Edit `pcp-home.html` and copy it over.

Static HTML — no build step, no dependencies. Open any file in a browser.
